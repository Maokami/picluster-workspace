picluster Workspace

Privacy policy

Effective date: 8 November 2026. Operator: Maokami.

picluster Workspace is a personal automation for its owner. It is not a public mailbox or calendar service.

Data accessed and purpose

Google sign-in provides basic account identity. With the owner's permission, the integration reads unread Gmail messages, including sender, subject, date, and selected text, and calendar details needed for the daily schedule. It uses this data only to generate the owner's requested daily briefing.

Mail candidates are filtered before model processing. GitHub notification mail, identifiable bulk mail, and repository content excluded by the operator's rules are omitted. The integration requests Gmail read-only and Calendar read-only scopes and does not modify mail or calendar data.

Processing and sharing

Selected message text and relevant calendar information are supplied to Anthropic through the owner's Claude account to generate the briefing. The resulting summary is sent through Telegram to the owner's configured chat. These providers process the supplied data under their policies and the owner's account settings.

The automation does not sell Google user data, use it for advertising, or operate a model-training pipeline. The operator must keep provider data-use settings consistent with the permitted briefing purpose and Google's Limited Use requirements.

Storage and retention

OAuth credentials are stored on the operator-controlled machine in owner-readable credential files. This integration does not publish credentials or message contents on this website or in its public source files. Selected mail is handled for the current run; the summarizer is configured not to save a local CLI session.

Generated summaries can remain in the owner's Telegram chat and local service logs until deleted or rotated. Anthropic, Telegram, Google, and this site's hosting provider apply their own retention policies to data they process. There is no promise that deleting a local file also deletes a provider's retained copy.

Control, revocation, and deletion

The owner can disable the scheduled briefing, revoke access in Google Account connections, and delete local credentials and summaries. Provider-held copies must be managed through the corresponding provider's controls. For questions or deletion assistance, contact the operator through the GitHub profile; do not post private messages or credentials in a public issue.

Google API Services User Data Policy

picluster Workspace's use and transfer of information received from Google APIs must adhere to the Google API Services User Data Policy, including its Limited Use requirements.

This information site

This static site has no analytics, advertising, account form, or application tracking script. Its hosting provider, GitHub Pages, may process ordinary web request information under the GitHub Privacy Statement.
